# Architecture Decision Records

Each ADR captures one significant decision: the context that forced it, the
choice made, and the consequences accepted. They are immutable — a decision
that is later reversed gets a new ADR that supersedes the old one, rather than
an edit that erases the reasoning.

Format adapted from Michael Nygard's template.
